# Customer Support Guide

## 🆘 Common Issues & Solutions

### "I can't upload my 360° photo"

**Solution:**
1. Make sure it's a JPG, PNG, or WebP file
2. File size should be under 50MB
3. Use Google Street View app for best results
4. Try a different browser (Chrome recommended)

### "The 3D view is not working"

**Solution:**
1. Make sure you're using a modern browser (Chrome, Safari, Firefox)
2. Enable WebGL in your browser settings
3. Try refreshing the page
4. Clear browser cache and cookies

### "I can't add products"

**Solution:**
1. Make sure you've uploaded a panorama first
2. Click anywhere on the 3D scene to place a product
3. Fill in the product name and price
4. Check your plan limits (Free: 50 products, Pro: 500 products)

### "My store link is not working"

**Solution:**
1. Make sure you copied the full link
2. Try opening in an incognito/private window
3. Check if the link has expired (regenerate if needed)
4. Contact support if the issue persists

### "I was charged but don't see my upgrade"

**Solution:**
1. Check your email for the Stripe receipt
2. Sign out and sign back in to refresh your session
3. Check the owner dashboard for plan indicator
4. Contact support with your order number
